Protocol accounting — the ledger

All 758 snapshot protocols in exactly one group. Nothing is dropped silently: a protocol is ranked, is a priced comparable, records a token with no usable cap, or is set aside for one stated reason.

Out-of-sample evidence — a term is kept only if it lowers the held-out miss in both tests, by more than noise

Miss is the typical miss: exp(median |log error|) on traded-token market caps, so ×3.33 means the typical priced cap is off by a factor of 3.33. Five held-out tests: leave-one-out over the 128 comps; walk-forward (fit on tokens listed before 2024-02-18, test the newer ones); by-category holdout (each category with n≥8 held out in turn); by-size holdout (fit the smaller half, test the larger, and the reverse); ten-fold cross-validation (deterministic folds by slug order). A term is kept only if it beats the last kept model by at least ×0.02 of miss in both the leave-one-out and walk-forward tests (0.002 of Brier for the odds) — a smaller gain is noise on 128 comps. The flat 0.25× multiple does not depend on any training set, so its by-category and by-size misses are the same medians over those subsets, not a copy error — the fitted terms are the ones that move across tests.

Token odds — Brier score, 645 peers with a listed date

Kin is not a fitted term. A name-stem match to a token that already trades would leak: token families cluster, so a fitted kin term scores a flattering Brier in-sample and means the opposite of what a reader needs. Kin rows instead get a visible badge and a stated heuristic odds discount of ×0.5, because a sibling token already trades. The control term — the growth of another row — must not help; if it did, the test would be broken.

Protocol detail

Model: implied value = size curve × category factor × token odds. Size curve ln(mcap) = a + b·ln(TVL), fitted on the 128 comparables at runtime; category factor = shrunk median residual per category (k=32, n≥3). Odds = logistic on no-token age, fitted on the 645 peers with a listed date (base rate in the odds table), ×0.5 for kin rows. The odds are the peers' record, not a forecast: this page never says a token will launch, or when. A protocol "records no token" in DefiLlama's record; that is not proof it has none.

Farm verdicts: FARM if net > $25 and net/hour > $25; MARGINAL if net > $0; otherwise SKIP. Net = airdrop slice − fees − time at $25/hour. Slice = implied value × drop share × (ticket / TVL). The default ticket is the plan size, 0.02% of each row's TVL: a flat $1,000 ticket makes the slice microscopic on every row (it tops out near $45), so every row would read SKIP and the verdict column would rank nothing — the flat $100–$10,000 tickets stay selectable and change the slice only; the step costs are fixed. Each plan deploys the minimum viable capital, sized from TVL ($50 below $100M, $100 at $100M+, $150 at $1B+, $250 at $5B+), and holds for 60 days if under 180 days old, 45 days if under a year, else 30 days. Fees: $2.00 bridge + gas on five steps at the primary-chain rate + 0.1% of the plan capital moved in the steps. No network is used by this page; all figures come from the sealed snapshot.
